# Code and data availability

The MPAS fork containing the Poisson solver is available at
[github.com/davidfillmore/MPAS](https://github.com/davidfillmore/MPAS)
on the `feature/poisson` branch.

## Manuscript

The manuscript describing this solver is archived as a preprint on
Zenodo:

- concept DOI:
  [10.5281/zenodo.21173830](https://doi.org/10.5281/zenodo.21173830)
  (resolves to the latest version);
- version 1 DOI:
  [10.5281/zenodo.21173831](https://doi.org/10.5281/zenodo.21173831).

Cite the concept DOI for a general reference to the paper, and the
version DOI when a reader needs the exact deposited manuscript.

## Documentation snapshot

The public Read the Docs documentation snapshot corresponding to this
narrative and its committed figure assets is archived as Zenodo release
`26.05.1` at
[10.5281/zenodo.20278575](https://doi.org/10.5281/zenodo.20278575); the
associated Zenodo concept DOI is
[10.5281/zenodo.19637632](https://doi.org/10.5281/zenodo.19637632). This
record is a documentation snapshot: the active Poisson solver
implementation remains on the `feature/poisson` branch. A separate
code-and-data release, including the benchmark NetCDF outputs used for
the figures, will be minted for the final publication archive.
