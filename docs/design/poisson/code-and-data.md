# Code and data availability

The MPAS fork containing the Poisson solver is available at
[github.com/davidfillmore/MPAS](https://github.com/davidfillmore/MPAS)
on the `feature/poisson` branch.

## Manuscript

The manuscript describing this solver is archived as a preprint on
Zenodo:

- concept DOI:
  [10.5281/zenodo.21173830](https://doi.org/10.5281/zenodo.21173830)
  (resolves to the latest version);
- version 1 DOI:
  [10.5281/zenodo.21173831](https://doi.org/10.5281/zenodo.21173831).

Cite the concept DOI for a general reference to the paper, and the
version DOI when a reader needs the exact deposited manuscript.

## Software archive

The fork is archived on Zenodo under concept DOI
[10.5281/zenodo.19637632](https://doi.org/10.5281/zenodo.19637632),
which always resolves to the latest version. The current release,
`MPAS-A-Electrostatics-v26.07`, is a full source-and-documentation
snapshot of the `feature/poisson` tree at the state described here:

- version DOI:
  [10.5281/zenodo.21177021](https://doi.org/10.5281/zenodo.21177021).

Cite the concept DOI to reference the software in general, and the
version DOI to pin the exact archived snapshot. An earlier
documentation-only snapshot, release `26.05.1`, is archived as version
DOI [10.5281/zenodo.20278575](https://doi.org/10.5281/zenodo.20278575)
under the same concept.

The archive contains the solver source and this documentation; the
benchmark NetCDF outputs used for the figures are generated by the
scripts under `src/core_atmosphere/electrostatic/scripts/` and are not
part of the repository archive.
